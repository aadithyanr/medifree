# medifree 🔓

tired of that annoying medium paywall? same here. this chrome extension automatically redirects medium articles to freedium. no more copy-pasting urls like a caveman.


## what it does

when you click on any medium.com link, this extension be like "nah fam" and sends you straight to the freedium version. smooth like butter. 

## installation

1. download this folder somewhere on your pc
2. open chrome and type `chrome://extensions/` in the address bar

3. turn on "developer mode" in the top right (don't worry, you're a developer now)
4. click "load unpacked" and select the folder you just downloaded

5. boom! you're done 🎉

## how to use

literally do nothing. just browse medium like you normally would. when you click a medium link, you'll automagically get the freedium version instead.
